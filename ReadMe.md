    Final project for module 4
    BEFORE RUN:
       1. Run docker 
       2. if if you are using an IDE, then in the terminal enter the command: **docker-compose up**
       3. If you are using the console, first make sure you are in the root of the project.
          If not, use the **cd** command to go there. Then run the command: **docker-compose up**.
       4. Wait for the docker container to start. 
          A dump of the **"world"** database will automatically occur during the first run.

    RUN:
       Use JAVA 17+
       To run the program from the console: 
            download the jar file from relises    
            make sure that you are in the directory where the jar file is located. If not, go to it.
            run the command: **java -jar Hibernate.Modul4-1.0-SNAPSHOT-jar-with-dependencies.jar**.
